<b>Disclaimer</b>: This is work in progress and not recommended for production mode testing. Nor is it meant to be a template of any kind that you might want to simply copy.

About
===

This project is my private testcase used exclusively for verification of the features that the ZUGFeRD / [Mustang project](http://www.mustangproject.org/) libs offer.

The latest version supports mustangproject version [2.26.0](https://github.com/ZUGFeRD/mustangproject/releases)

The main purpose of this program is to create a valid EXTENDED profile Factur-X compliant XML sample document that can be tested against the schematron verifier of our EDI provider for French eInvoicing.

This project is my private testcase used exclusively for verification of the 
features that the ZUGFeRD / mustangproject libs offer.

The current version supports mustangproject version 2.26.0

The main purpose of this program is to create a valid EXTENDED profile Factur-X 
compliant XML that can be tested against the schematron verifier of our EDI 
provider for French eInvoicing.
